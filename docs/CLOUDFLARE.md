# استقرار رایگان بک‌اند

بک‌اند این نسخه از Cloudflare Workers و D1 استفاده می‌کند. پنل اختصاصی `/admin` جایگزین Django Admin شده است تا به ماشین مجازی یا سرویس پولی نیاز نباشد. پلن Free سهمیه دارد؛ بدون تغییر پلن به Paid، عبور از سقف مصرف باید باعث خطا و تلاش مجدد همگام‌سازی شود. هیچ مرحله‌ای در گردش کار، حساب را به پلن پولی ارتقا نمی‌دهد.

## تنظیم یک‌بارهٔ حساب

۱. در حساب Cloudflare خود، امکان استفاده از `workers.dev` را فعال کنید. دامنهٔ اختصاصی و خرید دامنه لازم نیست.

۲. Account ID را از داشبورد همان حساب بردارید.

۳. در [API Tokens](https://dash.cloudflare.com/profile/api-tokens) یک توکن محدود به همان حساب بسازید با مجوزهای Account / Workers Scripts / Edit، Account / D1 / Edit و Account / Account Settings / Read. کلید Global API Key و رمز ورود را استفاده نکنید. توکن را در چت یا فایل‌های ریپو قرار ندهید.

۴. در [GitHub Actions Secrets](https://github.com/fayazamir1991/sms/settings/secrets/actions)، این مقادیر را با دکمهٔ New repository secret ذخیره کنید:

| نام Secret | مقدار |
| --- | --- |
| `CLOUDFLARE_ACCOUNT_ID` | Account ID حساب مقصد |
| `CLOUDFLARE_API_TOKEN` | توکن محدود ساخته‌شده در Cloudflare |
| `SERVER_RUNTIME_SECRETS` | تمام محتوای فایل خصوصی `SERVER_RUNTIME_SECRETS.json` |
| `ANDROID_KEYSTORE_BASE64` | تمام محتوای فایل خصوصی `ANDROID_KEYSTORE_BASE64.txt` |
| `ANDROID_SIGNING_PASSWORD` | تمام محتوای فایل خصوصی `ANDROID_SIGNING_PASSWORD.txt` |

سه مقدار آخر در بستهٔ خصوصی آماده‌سازی محصول قرار دارند. این بسته باید فقط نزد صاحب محصول بماند؛ آن را در بخش Code، Issue، Release یا پیام عمومی آپلود نکنید. فایل `ADMIN_LOGIN.txt` رمز ورود به پنل است؛ نیازی نیست آن را در GitHub ذخیره کنید.

## کار خودکار استقرار

گردش کار `Server tests and Cloudflare deployment` پس از موفقیت آزمون‌ها:

- دیتابیس اختصاصی `delneveshte-sms` را در همان حساب پیدا می‌کند یا می‌سازد.
- مهاجرت‌های دیتابیس را اجرا می‌کند. جاب مقداردهی اولیه، ۱۰۰۲ متن تألیفیِ متفاوت و ۷ بیت با انتساب شاعر را وارد می‌کند؛ در مجموع ۱۰۰۹ پیام. تکرار استقرار باعث تکرار رکوردها یا بازگرداندن ویرایش‌های مدیر نمی‌شود.
- Worker و پنل را منتشر و کلیدهای رمزگذاری و نشست را به Secrets خود Worker منتقل می‌کند.
- آدرس واقعی سرویس را در `app/api-base-url.txt` ثبت و ساخت APK با همان امضای قبلی را درخواست می‌کند.

پس از تنظیم Secrets، در زبانهٔ Actions گردش کار سرور را انتخاب کنید و Run workflow را بزنید. آدرس بک‌اند و `/admin` در خلاصهٔ اجرای موفق دیده می‌شود. رمز مدیریت در `ADMIN_LOGIN.txt` بستهٔ خصوصی است.

## نگهداری

کلید `DATA_ENCRYPTION_KEY` و کلید امضای APK باید در نسخه‌های بعد حفظ شوند. ساخت بستهٔ خصوصی تازه یا تعویض بی‌برنامهٔ کلیدها، راه آپدیت‌کردن محصول نیست. از دیتابیس D1 و بستهٔ خصوصی پشتیبان جدا نگه دارید. بدون کلید رمزگذاری، شماره‌ها و متن‌های خصوصیِ صادرشده از دیتابیس قابل خواندن نیستند.

شمارندهٔ نصب، تعداد نصب‌های ثبت‌شده پس از اتصال به سرور است؛ دانلود APK یا نصب کاملاً آفلاین قابل شمارش نیست. شناسهٔ تصادفیِ هر نصب و هش شناسهٔ مخصوص اپ در اندروید استفاده می‌شوند، نه MAC یا IMEI. آمار دستگاه نیز معادل تعداد افراد نیست.

دادهٔ صف روی گوشی مرجع ارسال است. سرور هرگز متن تازه‌ای را بدون انتخاب کاربر وارد صف گوشی نمی‌کند و دستور ارسال SMS صادر نمی‌کند. ثبت «ارسال‌شده» گزارش گوشی از ارسال به شبکه است، نه اثبات تحویل یا خواندن.
