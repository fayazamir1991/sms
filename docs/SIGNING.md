# امضای ثابت و حفظ اطلاعات هنگام آپدیت

نسخهٔ نصب‌شدهٔ صاحب محصول، APK دریافت‌شده از همین گفت‌وگو است. گواهی آن در `signing-certificate.sha256` ثبت شده است. فقط اثر انگشت عمومی در ریپو است؛ کلید خصوصی نباید وارد ریپو شود.

کلید موجود با حفظ دقیق همان گواهی به بستهٔ خصوصی `preserved-signing.p12` منتقل شده و رمز قوی گرفته است. Secretهای `ANDROID_KEYSTORE_BASE64` و `ANDROID_SIGNING_PASSWORD` از فایل‌های همان بسته تنظیم می‌شوند. نام کلید داخل کی‌استور `androiddebugkey` است؛ نام آن تغییری در هویت گواهی ایجاد نمی‌کند.

گردش کار جدید:

۱. آزمون‌ها و بررسی کد اجرا می‌شوند.
۲. همان کلید از GitHub Secrets در پوشهٔ موقت runner بازیابی می‌شود.
۳. APK نسخهٔ Release ساخته می‌شود.
۴. امضا با اثر انگشت نسخهٔ نصب‌شده مقایسه می‌شود؛ اختلاف امضا انتشار را متوقف می‌کند.
۵. فقط فایل تأییدشده در GitHub Release منتشر می‌شود.

اگر Secrets تنظیم نشده باشند، انتشار متوقف می‌شود؛ کلید تازه‌ای به‌صورت خودکار تولید نخواهد شد. فایل‌های قدیمی Release ۰.۱ و ۰.۲ با کلیدهای موقت محیط‌های ساخت امضا شده‌اند و با نسخهٔ نصب‌شده از چت هم‌امضا نیستند. برای مسیر آپدیت این صاحب محصول، گواهی ثبت‌شدهٔ همین پروژه مرجع است.

شناسهٔ اپ و دیتابیس موجود حفظ می‌شوند. مهاجرت نسخهٔ دیتابیس ۱ به ۲، شناسهٔ همگام‌سازی و صف رخدادها را اضافه می‌کند و متن، گیرنده و زمان‌بندی قدیمی را حذف نمی‌کند. پس از آپدیت برنامه را یک‌بار باز کنید. حذف برنامه یا پاک‌کردن داده‌ها روش آپدیت نیست.
