# Font Awesome navigation and action icons

Source: [Font Awesome Free 7.3.1](https://github.com/FortAwesome/Font-Awesome/tree/7.3.1/svgs/solid), released July 15, 2026. Style: Free Classic Solid. No Pro assets, paid service, icon-font runtime or network dependency is introduced.

The 14 Android navigation/action resources are adapted from original SVG paths with the original viewBox, using runtime tint. Original SVGs, per-resource mappings, source blob SHAs and URLs are preserved in manifest.json. The application launcher remains its own brand asset.

Icons: Copyright Fonticons, Inc., [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Conversion to VectorDrawable and runtime color tint are adaptations. LICENSE.txt is preserved here; credit and licensing are bundled in app/src/main/res/raw/fontawesome_license.txt and accessible from «درباره و مجوزها» in settings.

The pending palette options are separate from this icon update. A distributable APK will be prepared after the owner selects the new color direction.
