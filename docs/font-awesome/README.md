# Font Awesome navigation and action icons

Source: [Font Awesome Free 7.3.1](https://github.com/FortAwesome/Font-Awesome/tree/7.3.1/svgs/solid), released July 15, 2026. Style: Free Classic Solid. No Pro assets, paid service, icon-font runtime or network dependency is introduced.

The 14 Android navigation/action resources are adapted from original SVG paths with the original proportions, centered on square viewports without changing the paths, using runtime tint. Original SVGs, per-resource mappings, source blob SHAs and URLs are preserved in manifest.json. The application launcher remains its own brand asset.

Icons: Copyright Fonticons, Inc., [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Conversion to VectorDrawable and runtime color tint are adaptations. LICENSE.txt is preserved here; credit and licensing are bundled in app/src/main/res/raw/fontawesome_license.txt and accessible from «درباره و مجوزها» in settings.

The owner selected light violet and primrose (latest pastel comparison, option 2). Runtime tint follows the selected palette; original Font Awesome icon paths and licensing remain unchanged.

In 0.14.0, non-square SVG viewports are padded to a centered square instead of being stretched into a 24dp square. Source viewports and padded Android viewports are recorded in manifest.json; original SVGs remain unchanged. Icon buttons use CENTER_INSIDE and square 48dp or larger touch targets.
