نسخهٔ آزمایشی اولیهٔ دل‌نوشته برای اندروید.

- پیشنهاد پیام عاشقانه و شعر از بانک آفلاین.
- انتخاب شمارهٔ گیرنده، سیم‌کارت، تعداد روزانه و بازهٔ زمانی.
- صف پیام‌های تأییدشده، زمان‌بندی تصادفی، ارسال فوری و سابقهٔ ارسال.

فایل APK از اجرای موفق اولیهٔ GitHub Actions است. ارسال واقعی و نمایش در Google Messages باید روی گوشی بررسی شوند. این فایل با کلید توسعه امضا شده است.
