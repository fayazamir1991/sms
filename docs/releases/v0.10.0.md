# دل‌نوشته ۰.۱۰.۰ — بازطراحی با قرمز، صورتی چرک و طلایی

رابط فارسی و راست‌به‌چپ با الگوهای مدرن پیام‌رسان بازطراحی شد: ناوبری شناور، جست‌وجوی یکپارچه در نوار بالا، دکمهٔ شناور نوشتن، کارت‌های خواناتر، آیکن‌های هماهنگ و منو/دیالوگ‌های یکدست. پالت برند قرمز و صورتی چرک است و طلایی برای جزئیات زمان‌بندی استفاده می‌شود. فونت وزیرمتن داخل APK قرار دارد و به دانلود یا فونت گوشی وابسته نیست. پنل وب هم با همین پالت هماهنگ شده است.

مرجع کامپوننت‌ها کتابخانهٔ باز TelegramUI و الگوهای بازطراحی رسمی اندروید ۲۰۲۶ است؛ فایل Figma اولیه قابل استخراج نبود و مجموعهٔ آن قدیمی بود. توضیح منابع و توکن‌ها در [دیزاین سیستم](../DESIGN-SYSTEM.md) آمده است. این نسخه کپی پیکسلی فایل Figma یا رابط رسمی تلگرام نیست.

جست‌وجوی زنده، ضربدر پاک‌کردن، دو آیکن کارت و سه روش ارسال فوری، تصادفی و زمان دلخواه حفظ شده‌اند. صف، تنظیمات، پایگاه داده و امضای قبلی تغییر نمی‌کنند؛ روی نسخهٔ فعلی نصب کنید و اپ را حذف نکنید. تغییرات این نسخه عمدتاً ظاهری‌اند. برای رنگ تازهٔ پنل وب، آخرین main را در همروش Deploy کنید.

تصاویر ضمیمه از خود APK روی شبیه‌ساز اندروید ۱۴ گرفته شده‌اند. نسخه همچنان آزمایشی است؛ هیچ پیامک واقعی از محیط توسعه ارسال نشده است.
