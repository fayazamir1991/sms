# دل‌نوشته ۰.۱۱.۰ — لاکی و طلایی، با Font Awesome

پالت انتخابی مالک، گزینهٔ ۱، اعمال شد: قرمز لاکی `#C81D25`، درخشش گرم `#FF5A36`، طلایی `#D4AF37` و زمینهٔ عاجی `#FFFAF2`. صورتی از رابط حذف شده است. نور ظریف لبه و عمق کنترل‌های اصلی ثابت‌اند و نوشته روی بخش تیره و خوانا قرار می‌گیرد. برای متن و آیکن‌های طلایی، طیف خواناتر استفاده می‌شود.

۱۴ آیکن ناوبری و عملیات از Font Awesome Free 7.3.1 Classic Solid هستند. مسیر اصلی SVG حفظ و برای اندروید تبدیل شده؛ وابستگی شبکه یا آیکن‌فونت اضافه نشده است. منبع و مجوزها از «درباره و مجوزها» در تنظیمات قابل مشاهده‌اند. پنل وب نیز با پالت انتخابی هماهنگ شده است.

جست‌وجوی زنده، منوی کارت و سه روش ارسال فوری، تصادفی و زمان دلخواه حفظ شده‌اند. فونت وزیرمتن داخل APK است. امضا، پایگاه داده، صف و تنظیمات تغییر نمی‌کنند؛ روی نسخهٔ فعلی نصب کنید و اپ را حذف نکنید.

تصاویر ضمیمه از APK واقعی روی شبیه‌ساز اندروید ۱۴ گرفته شده‌اند. برای پالت تازهٔ پنل وب، آخرین main را در همروش Deploy کنید. نسخه آزمایشی است و هیچ پیامک واقعی از محیط توسعه ارسال نشده است.
