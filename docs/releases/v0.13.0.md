# دل‌نوشته ۰.۱۳.۰ — بنفشه روشن و زرد پامچال

گزینهٔ ۲ آخرین مقایسهٔ پاستلی اعمال شد: بنفشهٔ روشن `#8172B5`، زرد پامچال `#F4E89C` و زمینهٔ `#FBF9FD`. کارت‌های سفید، جزئیات یاسی روشن و متن تیره، این پالت را در اپ و پنل وب کامل می‌کنند. گرادیان و درخشش لاکی حذف شده‌اند. برای خوانایی نوشتهٔ کوچک و دکمه‌های سفید از طیف تیره‌تر بنفش استفاده می‌شود؛ رنگ انتخابی در عناصر برند حفظ است. آیکن‌های Font Awesome و فونت وزیرمتن باقی‌اند.

رفتار نسخهٔ ۰.۱۲، از جمله زمان مشخص همهٔ صف، ویرایش زمان و منوی کارت‌های صف، تغییر نکرده است. امضای قبلی و پایگاه دادهٔ نسخهٔ ۳ حفظ شده‌اند؛ APK را روی نسخهٔ فعلی نصب کنید و اپ را حذف نکنید. هیچ پیامک واقعی در محیط توسعه ارسال نشده است. نسخه آزمایشی است.

تصاویر ضمیمه از APK واقعی روی شبیه‌ساز اندروید ۱۴ هستند. برای رنگ تازهٔ پنل وب، آخرین main را در همروش Deploy کنید.
