# دل‌نوشته ۰.۱۷.۰ — جست‌وجوی خالی، ورود مستقیم به تایپ

جست‌وجو هنگام ورود از تب پایین یا دکمهٔ بالای صفحه خالی است. فیلد خودکار فوکوس می‌گیرد و کیبورد باز می‌شود. نتایج با تایپ عبارت و همان جست‌وجوی زندهٔ سراسری نمایش داده می‌شوند. ضربدر، متن و نتایج را بلافاصله پاک می‌کند و کیبورد برای جست‌وجوی بعدی آماده می‌ماند. خروج به صفحه‌ای دیگر کیبورد را می‌بندد؛ ورود تازه جست‌وجوی خالی باز می‌کند و لمس دوبارهٔ تب فعال فقط فوکوس را برمی‌گرداند.

عبارت خالی یا فقط فاصله، فهرست پیش‌فرض را نمی‌آورد و درخواست جست‌وجو به سرور نمی‌فرستد. درخواست قبلی و تایمر تایپ پس از پاک‌کردن نمی‌توانند نتایج را برگردانند. شمارندهٔ پیام‌ها از بالای بانک پیام و جست‌وجو حذف شد. بانک پیام‌ها همچنان پیشنهادهای اولیه و بارگذاری بیشتر دارد.

امضا، صف، زمان‌بندی، تقویم خورشیدی و تنظیمات قبلی حفظ شده‌اند. APK را روی نسخهٔ فعلی نصب کنید و اپ را حذف نکنید. نسخه آزمایشی است و هیچ پیامک واقعی از ابزار توسعه ارسال نشده است. تصاویر ضمیمه از APK واقعی روی شبیه‌ساز اندروید ۱۴ هستند.
