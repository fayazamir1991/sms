# دل‌نوشته ۰.۱۸.۰ — انتخاب لحن

- انتخاب «محاوره‌ای» یا «رسمی» در تنظیمات؛ پیش‌فرض محاوره‌ای است. بانک پیام و جست‌وجو از همان لحن استفاده می‌کنند.
- افزودن نسخهٔ محاوره‌ای به ۱۰۰۲ متن قبلی و ۲۰۰۰ پیام جدید، هرکدام در دو لحن، با ایموجی مرتبط. ساخت مجموعهٔ جدید از ترکیب صحنه‌ها و تأمل‌های تألیفی است؛ روش و منابع مطالعه در docs/CATALOG-TONES.md توضیح داده شده‌اند.
- شعرها در هر دو لحن با متن اصلی نمایش داده می‌شوند. منبع و مطالعهٔ زمینه‌ای خارج از متن پیامک‌اند.
- هر دو لحن متن‌ها در بانک آفلاین هم همراه اپ هستند. صف قبلی و زمان‌بندی‌ها حفظ می‌شوند؛ لحن جدید فقط روی پیشنهادها اثر دارد.
- پنل وب برای نثر دو فیلد ویرایش دارد؛ برای شعر یک فیلد. مهاجرت سرور افزایشی و تکرارپذیر است.

برای اعمال داده‌ها و API جدید روی سرور، آخرین main را در همروش Deploy کن. دیسک و کلیدهای قبلی را حفظ کن؛ تغییر متغیرهای محیطی لازم نیست. APK با همان امضای نسخه‌های قبلی، versionCode 21، منتشر می‌شود. انتشار آزمایشی است؛ ارسال واقعی SMS از ابزار توسعه انجام نشده است.
