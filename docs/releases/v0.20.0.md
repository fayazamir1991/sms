# دل‌نوشته ۰.۲۰.۰ — جست‌وجوی روان

- حذف اسکن کامل بانک آفلاین و تکرار همهٔ صفحه‌های کش از مسیر تایپ روی رشتهٔ اصلی. پردازش متن، خواندن کش و ارتباط سرور روی workerهای محدود انجام می‌شود؛ صفحه‌کلید برای پایان جست‌وجو منتظر نمی‌ماند.
- شروع جست‌وجوی محلی و API فقط پس از ورود حداقل دو حرف/عدد؛ فاصله، نیم‌فاصله و اعراب حرف اضافه محسوب نمی‌شوند. با یک حرف یا پاک‌کردن فیلد، نتایج و درخواست در انتظار پاک می‌شوند.
- فاصلهٔ ۳۵۰ میلی‌ثانیه پس از آخرین تایپ برای شروع جست‌وجو. کارهای قبلی لغو و پاسخ‌های دیررس نادیده گرفته می‌شوند؛ قطع اتصال HTTP هم خارج از رشتهٔ رابط کاربری است.
- نتایج در بخش‌های حداکثر ۲۰تایی با «بارگذاری پیام‌های بیشتر» اضافه می‌شوند. تطبیق‌های محلی یکجا جمع‌آوری نمی‌شوند؛ کش در قطعات ۶۴ ردیفی و نتایج با یک lookahead خوانده می‌شوند. جست‌وجو همچنان سراسری، با لحن انتخابی و بدون نتیجهٔ تکراری است.
- سوئیچ لحن، کشیدن برای تازه‌سازی بانک، محل دکمهٔ نوشتن، صف تأییدشده و توقف انتخابی کاربر حفظ شده‌اند.

امضا همان امضای قبلی است؛ versionCode 23. نیاز به تغییر سرور و ریست داده‌ها نیست. انتشار آزمایشی است؛ ارسال واقعی پیامک از ابزار توسعه انجام نشده است.
