# دل‌نوشته ۰.۲۳.۰ — حالت یک‌دست نوار پایین

- همهٔ تب‌ها، از جمله بانک پیام‌ها، رفتار انتخاب یکسان دارند.
- تب فعال متن و آیکون سفید با زمینهٔ بنفش دارد؛ تب غیرفعال متن و آیکون تیره و معمولی دارد.
- آیکون خانه بدون زمینهٔ جداگانه و با اندازهٔ ۱٫۵ برابر آیکون‌های دیگر نمایش داده می‌شود.
- امضای سازگار نصب قبلی حفظ شده است.
