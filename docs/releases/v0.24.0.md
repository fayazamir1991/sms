# دل‌نوشته ۰.۲۴.۰ — به‌روزرسانی از گیت‌هاب

- هنگام اجرای برنامه، آخرین ریلیز پایدار گیت‌هاب بررسی می‌شود و اگر نسخهٔ جدیدتری باشد، پیام دریافت به‌روزرسانی نمایش داده می‌شود.
- دریافت APK از دارایی ریلیز رسمی با DownloadManager انجام می‌شود و اعلان خود اندروید روند دریافت را نشان می‌دهد. در تنظیمات هم بررسی دستی اضافه شده است.
- پیش از بازکردن نصب‌کننده، نام بسته و گواهی امضای APK با برنامهٔ نصب‌شده تطبیق داده می‌شود؛ APK ناسازگار رد می‌شود.
- اندروید برای نصب خارج از فروشگاه اجازهٔ نصب از این منبع و تأیید نصب را از کاربر می‌گیرد. صف، زمان‌بندی و داده‌های محلی دست‌نخورده می‌مانند.
