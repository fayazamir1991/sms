# دل‌نوشته ۰.۲۵.۰ — به‌روزرسانی از سرور محصول

- بررسی نسخهٔ سرور در شروع برنامه و هر شش ساعت هنگام بازبودن برنامه، بدون مسدودکردن رابط.
- نشان قرمز نسخهٔ تازه روی تب تنظیمات و کنار بخش به‌روزرسانی؛ با ورود به تنظیمات نشان دیده‌شده محسوب می‌شود.
- APK نسخه‌ها در دیسک پایدار سرور `/data/app-releases` نگهداری می‌شود؛ GitHub Release فقط notes و پیش‌نمایش دارد و APK پیوست نمی‌کند.
- بارگذاری نسخه روی سرور با توکن محرمانه، کنترل SHA-256، نام‌گذاری نسخه‌ای و manifest اتمیک انجام می‌شود. برنامه پیش از نصب hash، نام بسته، شماره نسخه و گواهی امضا را تطبیق می‌دهد.
- اندروید همچنان اجازهٔ نصب از این منبع و تأیید نصب را از کاربر می‌خواهد. صف و داده‌های محلی تغییر نمی‌کنند.
