# دل‌نوشته ۰.۳.۰

- بانک سرور با ۱۰۰۲ متن عاشقانهٔ تألیفی با ایموجی مرتبط و ۷ بیت با ذکر شاعر؛ مقداردهی اولیهٔ یک‌باره و بدون رکورد تکراری.
- پنل فارسی مدیریت بانک پیام‌ها و مشاهدهٔ نصب‌ها، صف، رخدادها و گزارش ارسال.
- صف ابتدا روی گوشی ذخیره می‌شود؛ با فعال‌کردن همگام‌سازی، متن، شمارهٔ مقصد و وضعیت‌ها در پس‌زمینه با سرور همگام می‌شوند.
- شناسهٔ نصب پایدار و هش شناسهٔ مخصوص اپ؛ بدون خواندن MAC، IMEI یا صندوق پیامک.
- مهاجرت غیرتخریبی دیتابیس برای حفظ پیام‌های زمان‌بندی‌شده و تنظیمات قبلی.
- بررسی اجباری امضای APK با کلید نسخه‌های نصب‌شدهٔ قبلی؛ نصب به‌صورت به‌روزرسانی و بدون حذف اپ.

همگام‌سازی به اینترنت و اجازهٔ اجرای پس‌زمینه نیاز دارد. وضعیت ارسال، گزارش ارسال گوشی به شبکه است و رسید تحویل نیست. صف از سرور بازیابی نمی‌شود؛ اپ را برای آپدیت حذف نکنید. رفتار واقعی شیائومی و ثبت در Google Messages باید روی گوشی بررسی شود.
