# دل‌نوشته ۰.۵.۰

متن پیامک از اطلاعات منبع جدا شد. شاعر، سایت، پیوند و وضعیت بازنشر فقط در کارت پیشنهاد نمایش داده می‌شوند. بانک پیشنهادهای سرور با قالب فارسیِ بدون لینک بازسازی می‌شود؛ صف و سابقهٔ کاربران حذف نمی‌شوند. انگلیسی بدون ترجمه وارد بانک نمی‌شود. ترجمه به سرویس تنظیم‌شدهٔ صاحب محصول نیاز دارد؛ تا تنظیم آن، منابع انگلیسی وارد پیشنهادها نمی‌شوند. مجوز صاحب نمناک و تاوبیو در تنظیمات منابع ثبت شد.
