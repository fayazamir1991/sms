# دل‌نوشته ۰.۶.۰

- «پیشنهادهای تازه» واقعاً بانک سرور را دریافت می‌کند؛ کش عادی از ۱۲ ساعت به ۳۰ دقیقه کاهش یافت.
- بانک قبل از بارگذاری صف دریافت می‌شود تا خطای همگام‌سازی صف مانع تازه‌شدن پیشنهادها نشود.
- پیشنهادهای ندیده در گوشی مقدم‌اند؛ تا پایان گزینه‌های ندیده تکرار نمی‌شوند. پیام‌های انتخاب‌شدهٔ قبلی دوباره پیشنهاد نمی‌شوند.
- سرور برای هر نصب، پیشنهادهای تازه و کمتر دریافت‌شده را مقدم می‌کند؛ تصادفی‌بودن بین گزینه‌های هم‌اولویت حفظ می‌شود.
- زمان آخرین دریافت و خطای اتصال روی صفحهٔ پیشنهادها نمایش داده می‌شود.
